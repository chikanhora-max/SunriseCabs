# SunriseCabs 🇱🇰

A cinematic Sri Lankan car-rental showcase and booking experience.

## Direction

Automotive editorial design inspired by premium mobility, travel and luxury hospitality experiences — not a copy of any existing site.

## Fleet references

- Suzuki Wagon R
- Toyota KDH
- DFSK Glory

## UX

- Self-drive / with-driver flows
- WhatsApp-first booking
- Airport pickup
- Fleet comparison
- Sri Lankan destinations
- Vehicle spotlight animations
- Custom vehicle cursor
- Responsive and reduced-motion-friendly UI

## Research notes

Market references were checked against current Sri Lankan rental listings. Actual SunriseCabs rates and vehicle specifications should be confirmed with the business before publishing.

## Attribution

Third-party 3D assets, if used, must retain their original license/attribution requirements. Where an exact licensed model is unavailable, the UI uses original procedural vehicle forms rather than misrepresenting a generic model as a specific vehicle.
