## Accuracy policy

The showcase deliberately separates **verified/public Sunrise information**, **published rental-market reference data**, and **unverified showcase vehicles**. It does not invent customer testimonials, live availability, exact KDH/Glory Sunrise pricing, or business claims that could not be verified.

Before launch, re-check contact numbers, review count, prices, deposits, mileage allowances, vehicle availability and terms directly with Sunrise Cabs.

## Attribution

Third-party 3D assets and photography must retain their original license/attribution requirements. Where an exact licensed model is unavailable, the UI uses reference imagery or original/procedural presentation rather than misrepresenting a generic model as an exact Sunrise vehicle.
